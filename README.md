# whosNixck.github.io

Meine persönliche Portfolio-Website — gebaut mit purem HTML, CSS und JavaScript (kein Framework, kein Build-Schritt), mit Hilfe von Claude.

🔗 **Live:** [whosnixck.github.io](https://whosnixck.github.io)

## Struktur

```
index.html          Seitenstruktur & Inhalte
style.css            Styling (Dark Theme, Animationen, Responsive Layout)
script.js             Interaktivität (Sprachwechsel, Scroll-Animationen, Skill-Bars, Timeline)
translations.json    Alle Texte in Deutsch & Englisch
```

## Features

- Animierte Timeline, Skill-Bars und Scroll-Reveals
- Zweisprachig (DE/EN) über einen Switch oben rechts, Texte kommen zentral aus `translations.json`
- Vollständig responsive (Mobile bis Desktop)
